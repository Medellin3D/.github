![GitHub](https://img.shields.io/badge/GitHub-Medellin3D-black?logo=github)

## About Us ℹ️

Medellin3D is a company based in Medellín, Colombia that offers a range of 3D printing and design services. We transform ideas into physical realities, providing solutions for art, education, industrial parts, and large-scale sculptures. Our expertise lies in engineering projects and personalized advice, using quality materials and precision to create functional parts and sculptures for various industries. We specialize in large-format 3D printing for special projects like custom art and commercial installations, custom 3D design, 3D scanning, and maintenance services.

## What We Do 🔧

### Firmware Development ⚙️
- Custom Marlin firmware for popular 3D printer models
- Optimization for Artillery printers (Sidewinder X1, Genius)
- Configuration for MKS Robin Nano control boards
- Support for a wide range of 3D printers including Creality, Bambu, Prusa, Voron, and more

### Hardware Control Systems 🖥️
- Firmware for BIGTREETECH touchscreen interfaces
- Control systems for various 3D printer models
- Display and user interface enhancements

### Software Tools 💻
- Customized OrcaSlicer (G-code generator and slicer software)
- FarmDash - 3D printer farm management solutions
- Integration with automation workflows

### AI and Automation Integration 🤖
- Implementation of n8n workflow automation platform
- AI-enhanced 3D printing processes

## Open Source Projects ❤️

We build upon and contribute to the following open source projects:

### 3D Printing Ecosystem 🖨️
- [Marlin Firmware](https://github.com/MarlinFirmware/Marlin) - The dominant open-source 3D printer firmware
- [OrcaSlicer](https://github.com/SoftFever/OrcaSlicer) - G-code generator and slicer software
- [Klipper](https://github.com/KevinOConnor/klipper) - 3D printer firmware with emphasis on precision
- [BIGTREETECH TouchScreenFirmware](https://github.com/bigtreetech/BIGTREETECH-TouchScreenFirmware) - Firmware for 3D printer touchscreens
- [OctoPrint](https://github.com/OctoPrint/OctoPrint) - Web interface for 3D printers
- [RatOS](https://github.com/Rat-OS/RatOS) - Raspberry Pi distribution for 3D printing
